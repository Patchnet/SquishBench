# SquishBench

Public browser fidget toy and model bake-off harness.

SquishBench has two jobs:

1. **Reference app** — a load-in-browser stress-reliever (hands + squishy; ball / cow / pizza).
2. **Bake-off harness** — frozen prompts and `outputs/` snapshots so you can compare one-shot model runs and agent-manager multi-lane work product.

## Quick start

```bash
npm start
```

Then open the URL printed by the static server (default `http://localhost:4173`).

## Status

Seed scaffold. The reference app, prompts, and output layout land via Formal Flow PRs.
